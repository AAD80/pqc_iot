# Performance Evaluation of Lightweight Post-Quantum Cryptography for Resource-Constrained IoT Devices

This repository contains the data extraction and figure generation scripts for the manuscript:

> **Performance Evaluation of Lightweight Post-Quantum Cryptography for Resource-Constrained IoT Devices: An Experimental Comparative Study**

The scripts read the official [pqm4](https://github.com/mupq/pqm4) benchmark repository directly from GitHub, extract ML-KEM and ML-DSA performance data, compute summary statistics, and generate all tables and figures reported in the manuscript.
